<p>As campaign funnels evolved, we needed a more structured and scalable way to build complex ecommerce flows—particularly around bundles, upsells, and multi-step checkouts.</p>

<p>I was closely involved in the development and adoption of the NextCommerce Campaign Cart SDK, helping define how frontend interactions map to cart logic and backend systems.</p>

<p>This included:</p>

<ul>
  <li>Designing and implementing frontend patterns for bundle selection and upsells</li>
  <li>Developing campaign templates used across multiple brands</li>
  <li>Contributing to the SDK’s event model and data attribute system</li>
  <li>Ensuring consistency between UI state, cart behavior, and backend responses</li>
  <li>Improving developer experience through predictable integration patterns</li>
</ul>

<p>One of the main challenges was maintaining flexibility without breaking system integrity—allowing custom UI patterns while keeping the underlying cart logic stable.</p>

<p>The result was a more reliable and scalable way to build high-converting funnels, reducing edge cases and improving both developer velocity and user experience.</p>
